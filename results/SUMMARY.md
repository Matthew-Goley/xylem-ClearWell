Limitations (generated): 
- Only 2 district(s) were flood-mapped, so the district-level Spearman correlations have n = 2. With n this small the statistical power is very low and the results are indicative only; a permutation p-value cannot be small with so few districts.
- IDSP lists reported outbreaks only. Weeks without a report were set to zero, which assumes complete reporting inside the file's date coverage (2018-03-10 to 2020-10-28).
- Outbreaks depend on many things besides flooding (sanitation, reporting effort, population), and the outcome window is fixed in config.py.
- Weather in the file is a single-point value per report row, so rainfall exists only for districts and weeks that had an outbreak (the B2 baseline is biased towards outbreaks).
- 1 district spelling(s) in the file could not be matched (see results/idsp_district_mapping.csv).
- The index weights were fixed in config.py before looking at outbreak data.
