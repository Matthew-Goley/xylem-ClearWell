# Clearwell web map (static site)

A static page that shows the Clearwell village ranking on a map for district health
teams. Plain HTML, CSS and JavaScript with Leaflet 1.9.4 vendored in `vendor/leaflet/`.
No build step, no server code, no API keys, no analytics. The only network requests
outside this folder are OpenStreetMap map tiles.

```
frontend/
  index.html
  css/style.css
  js/app.js
  vendor/leaflet/        Leaflet 1.9.4 (BSD-2-Clause, see LICENSE)
  data/                  generated by ../export_web_data.py, do not edit by hand
    meta.json            event, scoring, accuracy, validation, case check, limitations
    villages.geojson     village proxy shapes + ranking
    districts.geojson    study district outlines
    flood_*.png          flood overlays (max extent + one per satellite pass)
    villages.csv         ranked list for download
```

## Preview locally

From the repository root:

```bash
python -m http.server -d frontend 8000
```

Then open <http://localhost:8000>. Opening `index.html` directly from disk will not work,
because browsers block `fetch()` of local files.

## Refresh the data

After any pipeline re-run (new scoring, more districts, more passes), from the repository
root and with the pipeline's Python environment active:

```bash
python export_web_data.py
```

It reads `outputs/villages.gpkg`, `outputs/aoi_districts.gpkg`, `outputs/flood_extent.tif`,
`outputs/flood_by_pass/*.tif` and the JSON/CSV files in `results/`, and rewrites
everything in `frontend/data/`. It also writes `outputs/web_alignment_check.png`
(village outlines drawn over a flood overlay) so you can confirm the layers line up.
Missing inputs are skipped and the page shows "not available" for them.

Commit the new `frontend/data/` files to update the deployed site.

## Deploy on Vercel

1. In Vercel, "Add New Project" and import the GitHub repository.
2. Set **Root Directory** to `frontend`.
3. **Framework Preset**: Other.
4. Leave the build command empty and do not override the output directory.
5. Deploy.

No `vercel.json` is needed: Vercel serves the folder as static files.

## Notes

- Map tiles come from `tile.openstreetmap.org` and must keep the attribution. Their
  [tile usage policy](https://operations.osmfoundation.org/policies/tiles/) suits light
  use like a prototype; heavy traffic would need another tile provider.
- Every number on the page comes from `data/`. If you change wording in `js/app.js` or
  `index.html`, keep to the copy rules: no em dashes, no exclamation marks, and no claims
  beyond the data.
